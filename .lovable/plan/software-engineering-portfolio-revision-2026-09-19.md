# Software Engineering Portfolio Revision

## Goal

Refocus the single-page portfolio for a software engineering student, remove all imagery and promotional filler, and preserve the bold split-screen interaction.

## Changes

- Replace every lime accent with white while retaining the black, paper, and electric-blue visual system.
- Remove all generated images and image-based layouts from the page.
- Keep the opening split selector, relabeled as **Personal** and **Perficient**, with concise labels only.
- Build the **Personal** view with two subsections:
  - **Projects:** placeholder cards with title, short description, and clickable placeholder GitHub links.
  - **Experience:** placeholder entries with role/company, dates, and a short description.
- Build the **Perficient** view as an expandable work area whose first section is **Certifications**.
  - Show certifications in a compact table split into **Ongoing** and **Completed** statuses.
  - Leave a restrained placeholder indicating that additional Perficient sections can be added later.
- Replace the existing approach section and promotional copy with direct, functional labels.
- Keep one global **Contact me** section, using placeholder links rather than inventing contact details.
- Update page metadata to describe a software engineering student portfolio.

## Interaction and presentation

- Switching the opening panels or the selector updates the content below and scrolls to it.
- Project cards behave as external GitHub links.
- Tables and cards remain readable on narrow screens without overlap.
- Existing typography and the selected cinematic dual-panel direction remain intact.

## Validation

- Verify both Personal and Perficient modes on desktop and mobile.
- Confirm every project card is clickable, certification statuses are visible, imagery is absent, and lime no longer appears.
- Confirm the page builds without errors.
